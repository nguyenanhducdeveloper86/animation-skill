# Animation Skill

Production animation guidance for AI coding agents building distinctive web experiences: spatial studio sites, editorial interfaces, product surfaces, and interactive 3D.

This pack combines motion direction, implementation patterns, accessibility, and performance. It is implementation-aware without forcing one library.

## Install

```bash
npx skills@latest add nguyenanhducdeveloper86/animation-skill
```

Codex users can also clone the repository and place a selected skill under the local skills directory.

## Skills

| Skill | Use it for |
|---|---|
| `web-animation` | End-to-end motion decisions, choreography, accessibility, and QA |
| `gsap-scroll` | GSAP timelines, ScrollTrigger, Lenis, and App Router lifecycle |
| `spatial-webgl` | R3F shared canvases, DOM↔mesh composition, camera rigs, and graceful fallback |
| `motion-taste` | Choosing what deserves motion, easing, hierarchy, restraint, and critique |

## Core rule

Do not add animation because a page is empty. Establish intent, hierarchy, state ownership, input behavior, reduced-motion behavior, and a measurable performance budget before writing effects.

## Reference influences

The pack is informed by public patterns from LottieFiles Motion Design Skill, Emil Kowalski's skills, GSAP's official skills, iart-ai Web Animation Skills, and Jakub Krehel's interface skills. It is an original synthesis, not a copy of their files.
